Dead Run is a side-scrolling runner game that I built for my A level Computer Science project.
This game includes features such as collision detection, scoring, player movement, game-state logic.
The design of the character in the game is inspired from the Japanese Ninja warriors and this character runs through every level to reach the ending gate.
I have built this game using JavaScript, HTML and CSS.
